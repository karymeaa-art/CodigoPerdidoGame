# Código Perdido: Escape del Sistema

Aventura de plataformas 2D hecha con HTML5 Canvas, CSS y JavaScript puro. Explora cinco sectores digitales junto a PIXEL, recupera recuerdos y descubre qué ocurrió con BYTE.

## Ejecutar

Abre `index.html` en un navegador moderno. No requiere instalación, dependencias, servidor ni conexión a internet. También se puede publicar directamente en GitHub Pages.

## Controles

- **A / D** o **← / →**: moverse
- **Espacio** o **↑**: saltar; doble salto al desbloquearlo
- **Shift**: dash
- **E**: interactuar, hackear terminales y resolver acertijos
- **Q**: congelar enemigos
- **R**: cambiar entre realidades
- **F**: usar el escáner y las habilidades de PIXEL
- **X**: activar el escudo cuando esté desbloqueado
- **Esc**: pausar

El progreso se guarda automáticamente en el almacenamiento local del navegador.

PIXEL puede escanear las cámaras secretas con **F**; acércate a la entrada detectada y pulsa **E** para explorarla. Los registros recuperados aparecen en el archivo de recuerdos y ayudan a desbloquear el final oculto. Las decisiones del núcleo y los finales descubiertos también se guardan automáticamente.

Al abrir el juego aparece la pantalla de inicio. **JUGAR** continúa el sector guardado o inicia una partida si todavía no hay progreso. **OPCIONES** permite ajustar el volumen, la música ambiental y los efectos; en navegadores compatibles también ofrece pantalla completa. El archivo de progreso sigue disponible desde la portada.
